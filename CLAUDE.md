# Правила проекта

Личное портфолио Дмитрия Шайбакова. Полное задание в `BRIEF.md`: прочитай его целиком перед работой.

## Git
- Автор коммитов только владелец: `git config user.name "Dmitry Shaibakov"` и `git config user.email "addictcode@users.noreply.github.com"`.
- Никогда не добавляй `Co-Authored-By` и «Generated with Claude Code» ни в коммиты, ни в PR.
- Работай в ветке, результат отдавай через PR в `main`. В `main` напрямую не пушь.

## Конфиденциальность (репозиторий публичный)
- Два кейса идут без названий: «сайт для дилера ворот и автоматики» и «CRM/ERP для сервисной компании». Не пиши названия компаний, домены, отрасль точнее, чем в брифе.
- Не упоминай место работы владельца и никакой email.
- Никаких выдуманных клиентов, отзывов и цифр. Факты бери только из `BRIEF.md`.
- Демо на выдуманных данных всегда подписаны как демо.

## Код
- Vite + React + TypeScript. Осмысленные имена, маленькие компоненты, без лишних зависимостей.
- Тексты только в `src/content/`, не в компонентах.
- Общение с владельцем: по-русски, на «ты», коротко и по делу.
